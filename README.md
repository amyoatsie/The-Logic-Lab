# The Logic Lab
A Capture the Flag style game designed to introduce students to CTFs within a contained environment.

<img src="blob:chrome-untrusted://media-app/de89bb92-7a59-4371-8057-3233b9a5b8be" alt="The Logic Lab.png"/><img width="1365" height="714" alt="image" src="https://github.com/user-attachments/assets/38a1a626-0024-4d90-ac9e-1282cb2ff68f" />

**Features:**
- Guest Access or Optional Sign Up
- Reset Progress for Signed in Users
- Current Functionality for only Case 1
- Notebook of Digital Forensic images
- Multi-choice questions to test Understanding

**How it Works and Limitations:**
The project works through a Tkinter Bootstrap and OOP design, with a custom colour scheme and separate folders.
The original design was made for a Software Development task, and therefore the key limitation was time, which is why only Case 01 currently has functionality.
Downloading the files and running them in an environment like Visual Studio Code will allow you to interact with the challenge.
